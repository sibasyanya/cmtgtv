# План реализации исправлений Cybermasters TG TV (CMTGTV)

## 1. Контекст и цели
Пользователь сообщил о следующих проблемах в приложении для Android TV:
1. **Авторизация по номеру:** Ввод номера телефона завершается тупиком — кнопка подтверждения («Получить код») обрезана снизу и не видна на экранах ТВ.
2. **Загрузка прокси с mtproto.ru:** При нажатии «Загрузить с mtproto.ru» пишется ошибка «Не удалось найти прокси» (проблема с HTML-парсингом `&amp;`, жестким regex и отсутствием резервных источников).
3. **Обрезанные кнопки в окне добавления прокси:** Нижний ряд («Отмена», «Сохранить») не помещается по высоте в окне `AddCustomProxyDialog`.
4. **Зависание статуса «Инициализация TDLib...»:** При установке соединения через прокси статус зависает, так как `ConnectionStateConnectingToProxy` не обрабатывался отдельно, а `connState == null` ошибочно трактовался как незавершенная инициализация движка.

## 2. Предлагаемые изменения

### 2.1. ТВ-интерфейс авторизации по номеру телефона (`QrAuthScreen.kt`)
- **Двухколоночный ТВ-вид:**
  - Левая колонка: заголовок, поле отображения введённого номера, понятная яркая кнопка «Получить код / Войти» с поддержкой D-Pad фокуса, подсказка и статус.
  - Правая колонка: компактная экранная цифровая клавиатура (0-9, Backspace, Очистить) с крупными кнопками для пульта.
- Кнопка авторизации всегда видна на экране без необходимости вертикального скролла.

### 2.2. Улучшение парсера и загрузчика MTProto (`MtprotoScraper.kt`, `TdLibManager.kt`)
- Декодирование HTML-сущностей (`&amp;` -> `&`, `%20` и др.) перед разбором.
- Гибкий парсинг URL прокси (поддержка `tg://proxy?server=...&port=...&secret=...` с любым порядком query-параметров).
- Парсинг секретов в различных форматах (hex `ee...`, base64, URL-encoded).
- Добавление резервных зеркал/эндпоинтов бесплатных MTProto-прокси для Telegram на случай недоступности или изменений разметки `mtproto.ru`.
- Понятные сообщения об ошибках при таймаутах сети.

### 2.3. Исправление окна добавления прокси (`ProxySettingsDialog.kt`)
- Переработка `AddCustomProxyDialog`:
  - Фиксированный заголовок диалога.
  - Скроллируемая центральная область с полями ввода (`verticalScroll(rememberScrollState())`) с максимальной высотой, адаптированной под 720p/1080p экраны TV.
  - Фиксированная нижняя панель действий с кнопками «Отмена» и «Сохранить», гарантированно находящаяся в зоне видимости и доступная для пульта.

### 2.4. Исправление статусов подключения TDLib (`QrAuthScreen.kt`, `TdLibManager.kt`)
- Добавление обработки `TdApi.ConnectionStateConnectingToProxy`: статус отображается как «Подключение к прокси...» (желтый/бирюзовый индикатор).
- Разделение проверки статуса авторизации и сети: если `authState` уже перешел в `AuthorizationStateWaitPhoneNumber` или `AuthorizationStateWaitCode`, статус не должен показывать «Инициализация TDLib...», а показывает реальное состояние готовности или соединения.

### 2.5. Версионирование
- Поднятие версии приложения до `1.0.22` (versionCode `23`) в `android/app/build.gradle.kts`, `package.json`, `CHANGELOG.md` и в интерфейсе приложения.

## 3. План верификации

### Автоматическая проверка
- Запуск `npm run lint` и `compile_applet` для проверки сборки Web/компонентов.
- Проверка синтаксиса и сигнатур Kotlin-кода через анализ зависимостей и типов TDLib.

### Пользовательское тестирование (на Android TV)
- Проверить отображение экрана ввода номера телефона: кнопка «Получить код» доступна сразу рядом с полем ввода.
- Нажать «Загрузить с mtproto.ru» в настройках прокси и убедиться, что список прокси успешно загружается.
- Открыть «Добавить свой прокси»: кнопки «Отмена» и «Сохранить» полностью видны на экране.
- Проверить подключение: статус «Инициализация TDLib...» корректно сменяется на статус прокси/ожидания ввода.
