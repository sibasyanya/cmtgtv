# Changelog

Все важные изменения проекта Cybermasters TG TV (CMTGTV) фиксируются в этом файле.

## [1.0.43] - 2026-10-25

### Безопасность и защита данных
- **Устранение утечки учетных данных в системный журнал Logcat (`TdLibManager.kt`):**
  - Маскирование номеров телефонов при авторизации (отображение только первых 4 и последних 2 цифр `+799***12`).
  - Полное сокрытие одноразовых кодов авторизации Telegram из Logcat (`[PROTECTED]`), предотвращающее перехват кодов третьими приложениями с разрешением `READ_LOGS`.
- **Защита ключей подписи релизных APK (`build.gradle.kts`, `.github/workflows/release.yml`):**
  - Чтение паролей хранилища ключей и алиасов из переменных окружения CI/CD (`KEYSTORE_PASSWORD`, `KEY_PASSWORD`, `KEY_ALIAS`) с безопасными локальными значениями по умолчанию.
- **Изоляция и внешнее управление Telegram API ID и Hash (`build.gradle.kts`, `TelegramMediaTvApp.kt`):**
  - `apiId` и `apiHash` вынесены в `BuildConfig` и системные переменные окружения `TG_API_ID` / `TG_API_HASH`.
- **Шифрование локальной базы данных TDLib AES-256 (`TelegramMediaTvApp.kt`):**
  - Реализован механизм автоматической генерации и защищенного хранения 256-битного мастер-ключа шифрования в изолированном хранилище приложения.
  - Сохранена полная обратная совместимость для существующих пользовательских сессий без принудительного разлогирования.
- **Маскирование учетных данных в настройках прокси (`ProxySettings.kt`):**
  - Добавлена обфускация и кодирование паролей SOCKS5/HTTP прокси в JSON конфигурации настроек с поддержкой деобфускации.
- **Валидация пакета обновления перед установкой (`AppUpdateManager.kt`):**
  - Внедрена обязательная проверка целостности загруженного APK через `packageManager.getPackageArchiveInfo`.
  - Добавлена проверка совпадения `packageName` (`com.tgmedia.tv`), исключающая возможность установки вредоносных или поврежденных пакетов.
- **Защита цепочки поставок в CI/CD GitHub Actions (`.github/workflows/release.yml`):**
  - Добавлена автоматическая верификация контрольных 4-байтовых ELF-заголовков (`\x7fELF`) и ненулевого размера для каждой загружаемой нативной библиотеки `libtdjni.so` (архитектуры arm64-v8a, armeabi-v7a, x86, x86_64).

## [1.0.41] - 2026-10-24

### Добавлено и улучшено
- **Просмотр фотографий в исходном качестве (HD / 4K) (`TvChatDetailScreen.kt`):**
  - При открытии фото на весь экран инициируется принудительное скачивание оригинального файла максимального разрешения (`fullFileId`) с наивысшим приоритетом.
  - Полноэкранный просмотрщик динамически переключается с предварительного превью на полноразмерный четкий оригинал сразу по завершении загрузки, отображая статус «✓ Исходное качество (HD)».
- **Полноценное воспроизведение видео через Media3 ExoPlayer (`TvChatDetailScreen.kt`, `build.gradle.kts`):**
  - Устаревший `VideoView` заменен на современный движок `Media3 ExoPlayer` и `PlayerView`, поддерживающий все форматы и кодеки Telegram (MP4, MKV, WebM, H.264, H.265/HEVC, VP9, AV1, а также круглые видеосообщения-кружочки `MessageVideoNote`).
  - Реализован информативный экран ожидания загрузки видеофайла с фоновым превью, индикатором процесса и автоматическим стартом воспроизведения при готовности файла.
  - Добавлено циклическое воспроизведение, плавающая кнопка закрытия и обработка кнопок пульта ТВ (ОК для паузы/старта, стрелки для перемотки).
- **Действия с сообщениями по аналогии с официальным Telegram (`TvChatDetailScreen.kt`, `TdLibManager.kt`):**
  - **Ответить (Reply):** быстрое цитирование выбранного сообщения с отображением карточки ответа над строкой ввода и отправкой `InputMessageReplyToMessage`.
  - **Переслать (Forward):** диалоговое окно выбора целевого диалога из списка чатов пользователя и пересылка через TDLib `ForwardMessages`.
  - **Удалить (Delete):** диалог подтверждения с выбором удаления «Для всех» (`revoke = true`) или «Только у меня» (`revoke = false`) через `DeleteMessages`.
  - Интуитивное контекстное меню действий, вызываемое нажатием кнопки ОК на выбранном сообщении с пульта ТВ.
